# ftfy for R

Repairing mojibake and related damage in text, as a port of Python ftfy. This glossary fixes the words used for how a repair is described and repeated.

## Language

**Fixer**:
A named transformation that repairs one kind of damage, such as `uncurl_quotes` or `restore_byte_a0`. Most fixers take text and return text; a few work on bytes in the middle of an encoding repair.
_Avoid_: fix, cleaner, filter

**Step**:
One recorded action in a repair: an action (`encode`, `decode`, `transcode`, `apply` or `normalize`) paired with a parameter naming a codec, a fixer or a normalisation form.
_Avoid_: explanation step, operation

**Plan**:
The ordered sequence of steps that turned one input string into its fixed text. A plan may have no steps, and a missing input has a missing plan, which is not the same as a plan with no steps.
_Avoid_: explanation, recipe

**Segment**:
The unit `fix_text()` repairs independently: one line of an input string, keeping its trailing newline, or a piece of at most `max_decode_length` characters when a line is longer. A plan from `fix_and_explain()` covers the whole string as one segment.
_Avoid_: line, chunk

**Replay**:
Applying a plan's steps in order to a string, with no detection of what is wrong with it. A replay fails when a step cannot be carried out on that string.
_Avoid_: re-fix, re-run

**Codec**:
A named, fixed mapping between bytes and characters that a step can encode with or decode with. Each codec has exactly one name.
_Avoid_: encoding (as a noun for the mapping), charset, converter

**Hole**:
A byte that a codec assigns no character to. Decoding a hole fails.
_Avoid_: gap, unassigned byte, undefined byte

**Sloppy codec**:
A codec with no holes, made from a Windows codec by giving each hole the character with the same number as the byte. It decodes any bytes without failing.
_Avoid_: lenient codec, permissive codec

**Mark**:
The declaration R attaches to a string saying how its bytes are to be read: UTF-8, latin1, bytes, or none (the session's native encoding, or plain ASCII). A mark is a claim about the bytes, not a guarantee that they are valid.
_Avoid_: encoding (for the mark), declared encoding

**Reference version**:
The pinned pair of one tagged release of Python ftfy and one Python version that a release of the package is matched against; currently ftfy 6.3.1 on Python 3.13. Changing either half is a move to a new reference version.
_Avoid_: upstream version, pinned version, target version

**Reference behaviour**:
What the reference version does. The package's correctness is judged against it.
_Avoid_: upstream behaviour, Python behaviour

**Snapshot**:
A committed record of reference behaviour on a fixed set of inputs, generated by running the reference version. The package's tests compare against snapshots; they never run Python.
_Avoid_: golden file, expected output, live comparison

**Departure**:
A deliberate, recorded difference from reference behaviour, which must not be changed back to match.
_Avoid_: known bug, divergence, deviation

## Evaluating column-aware repair

**Reachable target**:
The text a repair of one value can be expected to produce: its clean value, except that each character destroyed by the corruption stays as the replacement the corruption left. It equals the clean value when nothing was lost.
_Avoid_: expected output, best possible output

**Flagged value**:
A distinct, non-missing value of a column to which per-value encoding repair assigns a plan with at least one step.
_Avoid_: corrupted value (that is ground truth, not detection), detected value

**Support**:
The number of flagged values in a column on which replaying a given plan succeeds and gives the same text as the value's own encoding repair. A flagged value can support several plans at once.
_Avoid_: votes, count, frequency

**Dominant plan**:
The plan a column's repair is built on: the plan with the most support, provided its support reaches a minimum number of flagged values and more than half of them. A column may have no dominant plan.
_Avoid_: column plan, majority plan, commonest plan

**Diagnosis**:
The judgement about a column that a cause report states: its dominant plan, or that it has none. Evaluation scores the diagnosis, never the report's wording.
_Avoid_: cause report (that is the whole account, of which the diagnosis is one part), verdict

**New false positive**:
A value that column-aware repair does worse on than per-value `fix_text()`: either `fix_text()` gives its reachable target and column-aware repair gives anything else, or `fix_text()` leaves it unrepaired and column-aware repair changes it to anything other than its reachable target.
_Avoid_: regression, false fix

**Override**:
A value to which column-aware repair gives different text from per-value `fix_text()`. An override may be a new repair or a new false positive; only ground truth tells which.
_Avoid_: departure (that is a difference from reference behaviour), divergence, deviation, column fix

**Cause report**:
What column-aware repair tells the user about a column's encoding damage: whether a dominant plan was found, what mix-up it describes (which codec the text was in and which it was read as), whether characters were lost, and how many flagged values support it. It states what detection found, never that a column is clean.
_Avoid_: diagnosis (that is the judgement the report states, not the whole report), explanation (that is upstream's word for a plan), cause (on its own)
