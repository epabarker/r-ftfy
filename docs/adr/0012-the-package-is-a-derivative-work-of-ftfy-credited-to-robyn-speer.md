# The package is a derivative work of ftfy, credited to Robyn Speer as author, and discloses AI assistance

Everything taken from python-ftfy v6.3.1 is treated as derived from it under Apache-2.0, whether it was copied verbatim (the JSON test cases, regex text, character and entity tables), translated (the R code, ported tests, adapted docs) or generated by running it (codec tables, snapshots, the numeric-reference table). None of it is defended as uncopyrightable fact, and the package as a whole is a derivative work. Robyn Speer is listed in `Authors@R` as `aut` and `cph`, not `ctb`, because the heuristic, its test cases and most of its data are her work, and her README asks to be credited correctly. Her README also says a derived work must not hide its authorship, giving generative AI as an example. The package therefore says plainly in its README that the port was written with AI assistance. We chose to disclose this without first asking her, and accepted the risk that she objects later, over asking first or writing v0.1 by hand. Decided in https://github.com/epabarker/r-ftfy/issues/17.

## Consequences

- **Licence.** `DESCRIPTION` has `License: Apache License (== 2.0)`. The tarball ships no `LICENSE` file: the repo's full-text `LICENSE` is excluded by `.Rbuildignore`. There is no `NOTICE` file, because upstream has none.
- **Copyright file.** `DESCRIPTION` has `Copyright: See file inst/COPYRIGHTS`. That file lists each group of derived files with its source and keeps upstream's line `Copyright 2023 Robyn Speer`. It also states that the material was translated to R and modified, and points to the departure registry.
- **CPython and Unicode data are named as sources, not licensors.** The codec tables, the numeric-reference table and the `\s`/`\w`/`\d` sets were observed by running CPython. They are named in `inst/COPYRIGHTS` as facts about mappings, with no `cph` role and no PSF licence text, because no Python source is copied.
- **Derived files carry a header.** Every ported `R/` file, ported test file and `data-raw/` generator starts with a line like `# Derived from python-ftfy v6.3.1, <path>. Copyright 2023 Robyn Speer. Apache-2.0. Translated to R and modified; see inst/COPYRIGHTS.`
- **Files with no header.** `test_cases.json` stays byte for byte, so it gets a `README` beside it instead of a header. `R/sysdata.rda` carries no notice of its own: its generator script does.
- **Credit and citation come first.** The README opens by naming the package as a port of ftfy by Robyn Speer. `inst/CITATION` returns her Zenodo citation first, with her wording unchanged, followed by an entry for the R package.
